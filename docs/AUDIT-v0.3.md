# WebCut v0.3.0 → v1.0.0 全项目审查报告

> 审查日期：2026-10-31 · 基线 v0.3.0-studio（commit 43fcc87，32 commits，约 9400 行）
> 审查方式：源码通读 + 渲染管线逐路径验证 + 后端安全/成本面检查

## 一、总体评价

架构分层清晰（引擎 IIFE / 状态 / 渲染层 / 事件层 / 初始化），模块化组件（dispatch / dag-engine / node-registry / render-worker / cloud-sync）质量良好。核心链路（导入→解码→预览→导出、保存→恢复、AI 任务闭环）经真实测试可用。但审查发现 **4 个隐藏故障**（UI 存在但无实现或部分实现）与 **2 个资金/安全风险**，均已定位到行级证据。

## 二、隐藏故障（P0 —— 正确性，v0.4.0 立即修复）

| # | 故障 | 证据 | 影响 | 修复方案 |
|---|---|---|---|---|
| F1 | **蒙版 UI 完全无实现**：属性面板有 线性/圆形/矩形/钢笔 蒙版选择器，但渲染管线（EffectPipe.drawFrame / drawExportFrame）无任何 mask 代码——选了蒙版画面毫无变化 | `props.mask` 仅存在于存储(2509)与 UI(3675)，渲染路径 0 引用 | 用户选蒙版无效=假按钮 | EffectPipe 增加 canvas 合成蒙版（linear/circle/rect 真实裁切+羽化渐变+反转；钢笔标注开发中） |
| F2 | **关键帧动画导出不生效**：关键帧插值（DAGEngine.sampleParam）只在「选中片段有 renderGraph 且 Worker 可用」的预览分支生效；主线程预览与**导出管线均不采样关键帧**——预览动画导出后变静态 | sampleParam 渲染路径 0 调用（仅属性面板 addKeyframe 3731/3734） | 预览≠导出，违反一致性底线 | 导出前按关键帧采样 props（每帧 evaluate → 生效参数），预览主线程分支同样接入；采样函数为纯函数，预览/导出共用 |
| F3 | **移动端属性抽屉控件全部失效**：sheetProps 用 `cloneNode(true)` 克隆属性面板，但事件 listener 不随克隆——抽屉里所有滑块/开关拖动无响应 | 5986 行 clone 后无重绑（素材抽屉有 bindLibDrag 重绑，属性抽屉没有） | 移动端核心编辑功能不可用 | 抽屉不再克隆 DOM：抽屉 body 挂载真实属性面板容器（renderProps 目标可切换），或克隆后调用 renderProps 重建 |
| F4 | **变声 UI 无实现**：属性面板提供 萝莉/大叔/正太/机器人/电音 五种变声，音频管线 0 引用 | `props.voice` 仅 setter(3693) | 假按钮 | 按任务书「禁止伪造」原则：选项保留但加「开发中」标注（需 DSP 变调管线，列入 v0.5 音频系统） |

## 三、资金与安全风险（P0/P1）

| # | 风险 | 证据 | 等级 | 对策（v0.4.0 内做） |

## 四、架构与技术债（P2 —— v0.5/v1.0 渐进偿还）

| # | 问题 | 现状 | 计划 |
|---|---|---|---|
| A1 | 单文件巨石：index.html ~6000 行，UI/状态/引擎/导出全在一个 IIFE | 模块化组件已外置（js/），主文件仍巨石 | v0.5 起新功能一律独立 js 模块；主文件按区拆分（状态层/渲染层渐进外迁），不做一次性大重构（风险大于收益） |
| A2 | 双撤销体系：快照 undo（已验证）+ DispatchCore opLog 镜像（op 失败静默） | 并存工作，镜像 doc 允许漂移 | v1.0 协作前统一：快照撤销为真值，opLog 严格记录（失败改为可见告警） |
| A3 | props 与 renderGraph 双轨：Worker GPU 路径读 renderGraph，EffectPipe 读 props，同步靠 setClipProp | 关键帧时创建 graph，存在默认值覆盖风险 | F2 修复时统一采样入口（关键帧→props 生效值），graph 仅服务 GPU 路径 |
| A4 | EffectPipe.chromaKey 全局单槽缓存 | 多片段切换时缓存抖动 | v0.5 改为按 clipId LRU（≤4 槽） |
| A5 | 仓库含 5.5MB 测试视频（test.mp4/test2.mp4）+ paywall-test.html 遗留 | 增大仓库 | v0.4 移出 git 跟踪（本地保留） |
