## v0.5.0（2026-10-31）专业剪辑与音频

### 片段变速（真实全链路）
- clip.speed 0.25x–4x + 预设（常速/慢动作0.5x/快动作2x/延时0.25x）
- 画面：源时间映射 srcIn+(t-start)*speed；音频：playbackRate + 源区间重映射（全量/流式双模式）
- 导出：视频帧映射与音频离线渲染同一实现；时间线波形按速度映射；trimR 按速度限源
- 变速时长语义：时间线时长不变、源消耗=时长×速度；超源自动回拉

### srcIn 源内偏移（修复预存正确性 bug）
- 修复：分割后右半段从源头部重放 → 现从分割点源位置接续
- trimL 推进 srcIn（不可裁到源起点前）；trimR 限源；分割/复制/粘贴全链路携带

### 音量包络线（AudioEnvelope）
- clip.props.env 折点（时间线相对 0–1 × 增益 0–200%）
- 属性面板 canvas 编辑器：点击添加/拖动调整/双击删除
- 播放：GainNode linearRamp 自动化；导出：离线渲染折点写入（真实验证 RMS 0.104→0.019）

### 转场库（真实混合渲染）
- 叠化（前帧垫底交叉混合）/ 黑场渐入 / 滑动位移入场；时长 0.2–2s
- drawLayerStack 统一预览与导出渲染（含效果/关键帧/转场）；时间线冰蓝渐变标记

### 关键帧与批量
- 关键帧复制/粘贴（跨片段携带动画曲线+标记）
- 多选批量属性栏：以当前片段为模板一键应用变换/调色/变速/转场/包络

### 修复
- drawLayerStack 帧取用（videoLayersAt 不含帧）；scheduleClip 残留 dur 引用（播放崩溃）

### 验证
分割接续 srcIn=1.0 ✓；2x 源消耗 8.14s ✓；转场中点混合非黑 ✓；2x 帧映射源 2.6s 出画 ✓；
