# WebCut 更新日志

## v0.3.0-studio（2026-10-30）产品级全面升级

### 视觉
- 全新「Graphite & Ice」设计系统：深石墨黑分层 + 银白文字 + 冰蓝强调 + 紫 AI 辅助
- 去霓虹/渐变/玻璃滥用，实色面板 + 1px 细线 + 克制阴影，电影工业级观感
- Canvas（时间线/播放头/片段/预览）配色同步换装

### 时间线
- 多片段选择（Ctrl 点选 + 空白框选）、右键上下文菜单
- 复制 / 粘贴 / 创建副本（Ctrl+C/V/D），跨轨道粘贴
- 整组拖动（吸附基准平移）、批量分割/删除
- 片段关键帧菱形标记可视化
- 新快捷键：Ctrl+C/V/D/A、Esc

### 属性与效果
- 属性面板全面 Schema 驱动（NodeRegistry uiSchema 生成）
- 第二批节点注册：模糊 / 锐化 / 色度键；变换新增裁剪 L/R/T/B；调色新增色相旋转/高光/阴影
- 全新 EffectPipe 真实效果管线（预览与导出同一实现）：
  变换/裁剪/不透明度（矩阵）、亮度/对比度/饱和度/色相/模糊（CSS filter）、
  色温/色调/高光/阴影（动态 SVG）、锐化（卷积）、色度键（逐像素 YCbCr）
- 关键帧参数扩展：模糊、亮度

### AI 创作中心
- 全新 10 项功能工作区：文生视频 / 图生视频 / 图片生成 / AI 配音 / 智能抠像 / 视频增强 / 风格转换 / 创意辅助（可用）+ 智能字幕 / 背景移除（如实标注开发中）
- 任务全生命周期：提交 → 进度 → 取消（联动上游）→ 预览 → 一键入时间线 → 失败重试
- AI 提示词润色（Qwen）内嵌各生成面板
- 后端新增：图生视频（i2v）、文生图（t2i）、提示词润色（qwen）、任务取消端点

### 导出
- 分辨率 720P/1080P/2K/4K；帧率 24/30/60FPS；视频码率自动/8/12/20/40Mbps；音频码率 128/192/256k
- 剩余时间估算、失败重试、完成提示带参数
- 自动码率公式升级（0.08bpp/帧，上限 48Mbps）

### 架构
- App.dispatch(op) 统一分发：JSON Pointer（RFC 6901 索引式）+ DispatchCore 校验 + opLog 镜像流水
- __EDITOR__ 暴露 App/EffectPipe/ops/opLog（集成与测试入口），版本 0.3.0-studio
- 全局错误收集器 __ERRS__

### 项目管理
- 多项目：列表 / 打开 / 重命名 / 副本 / 删除；每项目滚动保留 5 个版本快照
- 工程导入 / 导出 JSON（.webcut.json）
- 入口：用户菜单 → 项目管理

### 移动端
- 修复：桌面加载→窗口缩窄后底部导航失灵（动态视口）

### 安全
- 修复静态服务敏感文件泄露（.env API Key / 支付数据）——目录+扩展名双重黑名单

### 性能
- 预览画质降档（720/540/360p）
- EffectPipe 缓存（SVG 滤镜惰性重建、色度键单槽缓存）、删除片段自动释放滤镜
- 实测：空闲 59.9 FPS / 属性写入 100 次 5.3ms / 内存 21MB
