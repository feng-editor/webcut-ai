## 五、性能优化报告

- 预览画质降档（qualSel）：大工程可将预览背衬分辨率降至 360p，解码/绘制压力线性下降
- EffectPipe 缓存：SVG 滤镜惰性重建（参数 hash 相同直接复用）、色度键单槽缓存 + 预览降采样
- 删除片段自动 dispose 动态滤镜（DOM 不积累）
- op 记录 try/catch 隔离：DispatchCore 异常不阻塞渲染主路径
- 实测：空闲 59.9 FPS；100 次滚动 0.2ms；100 次属性写入（含 op+重绘）5.3ms；内存 21MB

## 六、部署说明

### 本地开发（与升级前一致）
```bash
cd ai-backend && python server_flask.py   # 8787 端口，同源访问 http://127.0.0.1:8787
```
依赖：`pip install flask flask-cors requests`（或 requirements-docker.txt）

### Docker（阿里云 ECS）
```bash
docker-compose up -d --build
```
升级后需在服务器执行 `git pull && docker-compose up -d --build` 拉取新版。

### Netlify 前端
netlify.toml 代理配置不变，推送后自动部署。

### 数据库/配置迁移说明
- **无需迁移**：IndexedDB 结构向后兼容；旧工程恢复时 `normalizeProps` 自动补齐新属性字段（裁剪/高光/阴影/锐化/色度键等默认值）
- 新增 IndexedDB 键：`project-index`（项目列表）、`project:<id>`、`project:<id>:v0..v4`（版本快照）
- AI 新能力依赖 .env 可选变量：`AI_I2V_MODEL`（默认 wanx2.1-i2v-plus）、`AI_T2I_MODEL`（wanx2.1-t2i-turbo）、`AI_TEXT_MODEL`（qwen-plus）

## 七、已知依赖与限制（如实声明）

1. **DashScope API Key 当前失效**（401 InvalidApiKey）：文生视频/图生视频/图片生成/提示词润色的云端生成不可用，前端如实显示上游错误；本地抠像/增强/风格转换/导出不受影响。更新 `ai-backend/.env` 的 `DASHSCOPE_API_KEY` 即恢复。
2. AI 智能字幕、背景移除、超分、神经风格迁移为**开发中**（依赖 ASR/分割/超分模型服务），UI 明确标注，未伪装。
3. 部分浏览器（Safari<16.4）WebCodecs 能力受限，导出自动降级 WAV 纯音频（原有行为保留）。
